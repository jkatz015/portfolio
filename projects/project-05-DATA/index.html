D.A.T.A.
Dashboard & Analytics Tool for Accounting

What it does: D.A.T.A. is a Streamlit web application that automates financial data analysis. Upload any CSV or Excel file with financial data, and the app will automatically detect column types (dates, amounts, categories), clean the data, calculate KPIs, and generate interactive visualizations. Perfect for analysts who want to spend less time on data prep and more time on insights.
